Source watch

AVA checks official pages on a schedule and tells you when something changes (a fee, a notice, a schedule). It only reads and reports. It never changes what AVA knows: you read each change, update AVA yourself, then mark it done. Pages that ask not to be read by automated tools are skipped.
Paste an announcement
For news that only exists on Facebook or other places AVA is not allowed to read. Paste the text of one post. AVA summarises it and checks that every point quoted really appears in what you pasted. Then it waits in the list above for you to review.
